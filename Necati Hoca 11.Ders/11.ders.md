# 11. DERS

## Const Member Functions

```cpp
class Myclass
{
public:
    void foo();        // Myclass*
    void bar() const;  // const Myclass*
};
````

```cpp
int getX() const { return mx; }
// c-> int getX(const Myclass* this) { return this->mx; }
```

---

### Const fonksiyon içinde veri değiştirilemez

```cpp
class Myclass
{
public:
    void foo(); // Myclass*

    void bar() const // const Myclass*
    {
        mx = 23;  
        // HATA:
        // const Myclass* olduğu için mx değiştirilemez
    }

private:
    int mx_;
};
```

---

### Const fonksiyon içinde non-const fonksiyon çağrılamaz

```cpp
class Myclass
{
public:
    void foo(); // Myclass*

    void bar() const // const Myclass*
    {
        foo();
        /*
        Eğer const bir üye fonksiyon içindeysek,
        this pointer const Myclass* türündedir.

        Bu yüzden const olmayan bir fonksiyon çağrılamaz.
        */
    }

private:
    int mx_;
};
```

---

### Const object davranışı

```cpp
const Myclass obj;

obj.bar(); // OK
obj.foo(); // HATA (non-const fonksiyon)
```

## this pointer ve dönüş tipleri

```cpp
Myclass* foo()
{
    return this;
}
```

---

```cpp
Myclass* bar() const
{
    /*
    HATA:

    this -> const Myclass*
    dönüş -> Myclass*

    const Myclass* → Myclass* dönüşümü yok
    */
}
```

## Pointer overload

```cpp
class Myclass {};
```

```cpp
// non-const overload
void foo(Myclass*)
{
    std::cout << "Myclass* called" << std::endl;
}

// const overload
void foo(const Myclass*)
{
    std::cout << "const Myclass* called" << std::endl;
}
```

```cpp
int main()
{
    const Myclass obj;
    Myclass obj2;

    foo(&obj);
    foo(&obj2);
}
```

### ÇIKTI

```
const Myclass* called
Myclass* called
```

# this Pointer

* Üye fonksiyonun çağrıldığı nesnenin adresini tutar
* Türü: `Myclass*` veya `const Myclass*`

### Özellik

* `this` ifadesi **prvalue**
* Sol tarafta kullanılamaz (assignment)

---

```cpp
class Myclass 
{
public:
    void foo()
    {
        this; 
        // çağrılan nesnenin adresi
    }
};
```

---

### this kullanımı

```cpp
void Myclass::foo()
{
    mx = 5;
    this->mx = 10;
}
```

---

## this ile fonksiyon çağrısı

### 1) Pointer ile

```cpp
void gfunc(Myclass*);

void Myclass::foo()
{
    gfunc(this);
}
```

---

### 2) Referans ile

```cpp
void gfunc(Myclass&);

void Myclass::foo()
{
    gfunc(*this);
}
```

---

### 3) Fluent API

```cpp
f.foo().bar();
```

# ODR (One Definition Rule)

* Her şeyin **tek tanımı** olmalı

```cpp
int x;
int x; // HATA
```

---

```cpp
int foo();
int foo(); // OK (redeclaration)
```

---

```cpp
extern int x;
extern int x; // OK
```

---

## ODR Violation

* Aynı şey birden fazla tanımlanırsa hata

### İstisna:

* Token-by-token aynıysa sorun yok

# Inline Functions

* Compiler optimization
* Fonksiyon çağrısı yerine direkt kod koyulur

---

## Şartlar

1. Derleyici fonksiyonun tanımını görmeli
2. Fonksiyon küçük olmalı
3. Derleyici desteklemeli

---

```cpp
int Myclass::getX()
{
    return mx;
}
```

---

## Notlar

* Class içinde tanımlanan fonksiyonlar **implicit inline**
* `constexpr` fonksiyonlar da implicit inline
* Inline fonksiyonlar **ODR violation oluşturmaz**

---

## Dikkat

```cpp
void Myclass::func()
```

Ayrı tanımlarsan → ODR violation olabilir
