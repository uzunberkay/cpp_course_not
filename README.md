# C++ Ders Notları (Necati Ergin)

Bu repo, **Necati Ergin'in C++ kursunu** takip ederken *ders ders* aldığım notları içermektedir.  
Notlar; konuların özünü, önemli detayları, örnek kodları ve derste vurgulanan kritik noktaları kapsar.

## 📘 İçerik

- Derslere göre sınıflandırılmış başlıklar  
- Sık yapılan hatalar, dikkat edilmesi gereken noktalar ve ek açıklamalar  

## 🎯 Amacım

- Dersi takip ederken hem kendi başvuru kaynağımı oluşturmak  
- Zaman içinde eksiksiz, ders sıralı bir C++ not arşivi meydana getirmek  
- Tekrar sırasında önemli noktaları hızlıca hatırlamak  
- Standart C++ yaklaşımını ve iyi pratikleri derli toplu bir şekilde kaydetmek  

## 📂 Yapı

Notlar genellikle şu formatı izler:

- **Ders başlığı*
- Önemli kavramlar
- Kod örnekleri
- Derste verilen ipuçları
- Kısa özet
